# Research

Create `research/<topic>/brief.md` from the [brief template](../templates/research-brief.md).

For each execution, create `research/<topic>/runs/<run-id>/run.md` from the [run template](../templates/research-run.md). Store original responses as `output.md`, reviewed synthesis as `assessment.md`, quality checks as `evaluation.md`, and supporting source records or results under `evidence/` in that run directory. Small assessments may combine records if their responsibilities remain clear.

Reusable test and benchmark code belongs in `research/<topic>/verification/`; record its exact revision and actual results in each applicable run. Do not label a test plan as an executed result.

Briefs define durable inputs. Runs record exact versions, dates, capabilities, evidence, and findings. Cite exact upstream revisions and their verification status when synthesizing dependent questions.
