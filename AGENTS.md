# Agent guidance

Decision Kit maintains reusable research specifications, evidence, and human-reviewed engineering decisions.

Read [the requirements](docs/technical-research-decision-requirements.md) before changing the framework or its workflows. When reviewing or standardizing research inputs, apply [the research brief review instructions](instructions/research-brief-review-instructions.md). Follow [the contribution workflow](CONTRIBUTING.md) when preparing changes.

Keep research inputs provider-independent. Record model configuration and execution details in run records. Do not answer research questions while only standardizing a brief.

Keep original model outputs distinct from reviewed assessments. Cite supporting evidence for material claims and state unavailable capabilities, unknown metadata, and unperformed checks honestly.

An agent must not invent approval, change organizational policy independently, or silently rewrite an accepted decision's rationale. Propose changes for human review and link superseding decisions when appropriate.

Use relative links within this repository and exact revisions when recording historical inputs. Check changed Markdown links and template consistency. Do not claim a test or review ran unless it did.
